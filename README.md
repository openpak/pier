# Pier Emulator

OpenPak's Pier Emulator.

| | |
| --- | --- |
| Console | PS3 |
| Kind | Emulator |
| Based on | [RPCS3](https://github.com/RPCS3/rpcs3) (GPL-2.0-only) |
| Licence | GPL-2.0-only, see [LICENSE](LICENSE) |

## What it does

- Runs the console's own PS3 firmware (the XMB) on an emulated console.
- Points the firmware at OpenPak's replacement PS3 online services through OpenPak's DNS by default.
- Is a fork of RPCS3; OpenPak's own changes are listed in [provenance](docs/provenance.md).
